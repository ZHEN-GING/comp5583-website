V2 - GENE_XU: A Little City of Ideas
Open index.html in a modern browser, or serve this directory with a static HTTP server. No install, build, backend, account, external fonts or API keys required. All media is local.
Navigation: use Home/About/Projects/Contact normally, click the four city labels, or focus the map and walk with WASD/arrow keys. Enter near a door opens its section. Tab leaves the map. Reset walk returns to the central square. Close or Escape returns focus to the entry point. On phones, use ordinary navigation or the large destination buttons below the map.
The four original V0 sections and two real projects are preserved. Text and photos remain normally rendered; only the procedural canvas uses pixelated scaling. With JavaScript unavailable the static sections remain in the HTML. Native video controls, disclosures, full-size image links and source acknowledgment are retained.
Development: independently copied from frozen V0, then rebuilt using development-time TF-IDF retrieval. Full experiment records: ../../task3-records/V2-RAG-rebuild-2026-10-20/README.txt. The previous V2 is backed up separately under ../../snapshots/V2-before-rebuild-2026-10-20. Not derived from V1.
The city artwork is original procedural code. Technical source notes and retrieved passages are attributed in the experiment records. Original project media and personal content remain subject to the same permissions as V0. This is a local candidate, not a public deployment or a newly frozen baseline.
