## Run Locally

Download or clone this repository. Each version has its own folder
containing an index.html file and the required assets.

Open V0/index.html, V1/index.html, or V2/index.html in a browser.

Alternatively, with Python installed, run this command from the
repository root:

    python -m http.server 8000 --bind 127.0.0.1

Then visit:
- http://127.0.0.1:8000/V0/
- http://127.0.0.1:8000/V1/
- http://127.0.0.1:8000/V2/

No build step, API key, or backend service is required.
For reliable video seeking, use the live GitHub Pages websites.
