Art & references

Made for this neighborhood

The district, character, buildings, street details and bitmap signs are original procedural pixel artwork created for this portfolio. No game sprites, textures or third-party code were copied. Body text uses system fonts.

Design inspiration

  • Taha Raouf — terminal-style headings and readable portfolio sections.
  • A. Sharan — exploring places as an optional route into portfolio content.
  • Streets of Rogue — a top-down urban pixel-art direction. No assets taken from the game.

Project media & code

The project photographs, award certificate and demonstration video were supplied by the portfolio owner. Project code credits and their known limitations are retained in the Projects section.
